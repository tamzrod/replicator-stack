# Laboratory Investigations

**Phase**: Investigation (Research Phase)

## Purpose

This directory contains **Investigations** - the Research phase of the Scientific Learning Loop.

## Workflow Position

```
Research ──creates──► Knowledge ──tests──► Laboratory
    ▲                                       │
    │                                       ▼
    │            Governance ──directs──► Evidence
    │              │
    └───────informs
```

## Investigation Activities

1. **Define Question** - Identify knowledge question
2. **Conduct Investigation** - Literature review, analysis
3. **Propose Definition** - Create candidate knowledge

## Naming Convention

Investigations are numbered sequentially:

```
INV-001/
INV-002/
...
INV-XXX/
```

## Investigation Structure

Each investigation should contain:

```
INV-XXX/
├── PLAN.md          # Investigation plan
├── README.md        # Investigation results
├── evidence/        # Evidence collected
└── (other files)    # Supporting documents
```

## Related Directories

| Directory | Phase |
|-----------|-------|
| `experiments/` | Experiment phase (Laboratory) |
| `evidence/` | Accumulated evidence |
| `validations/` | Validation results |
