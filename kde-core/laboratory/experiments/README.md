# Laboratory Experiments

**Phase**: Experiment (Laboratory Phase)

## Purpose

This directory contains **Experiments** - the Laboratory phase of the Scientific Learning Loop.

## Workflow Position

```
Research ──creates──► Knowledge ──tests──► Laboratory
    ▲                                       │
    │                                       ▼
    │            Governance ──directs──► Evidence
    │              │
    └───────informs
```

## Experiment Activities

1. **Design Experiment** - Plan validation methodology
2. **Execute Experiment** - Run tests, collect observations
3. **Verify Expectations** - Compare results vs human expectations
4. **Accumulate Evidence** - Document findings with citations

## Naming Convention

Experiments are numbered with LAB prefix:

```
LAB-001/
LAB-002/
...
LAB-XXX/
```

## Experiment Structure

Each experiment should contain:

```
LAB-XXX/
├── PLAN.md          # Experiment plan
├── RUN.md           # Execution log
├── RESULTS.md       # Raw results
├── ANALYSIS.md      # Data analysis
├── EVIDENCE.md      # Documented evidence
└── (other files)    # Supporting documents
```

## Evidence Requirements

All experiment findings must include:

- `[EVIDENCE: source]` - Verified source with citation
- `[INFERENCE: conclusion]` - Reasoning from evidence
- `Hypothesis:` - Explicitly labeled speculation
